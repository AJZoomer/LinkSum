About

LinkSum is a game I created when I was bored one day and just wanted to make something. This game is a simple number game about connecting tiles and hitting a target number, but over time it grew into something much more polished. I made this game because I wanted a puzzle game that feels good to play on all devices while remaining simple and not overloaded with features. LinkSum is a game you can play casually or chase streaks if you want a challenge. If you do enjoy this game consider sharing it with others who like puzzles.
